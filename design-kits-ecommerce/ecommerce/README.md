# Ecommerce kit (стартовая система для интернет-магазинов)

Основа для любого нового e-commerce дизайна: корзина, окно редактирования набора, страница товара, мини-корзина и чекаут. Собрана по структуре настоящих магазинов (Shopify-подобные корзины, Aureon, Rooted, OakHaus и другие референсы из UI-References). Пример бренда: Ember (кофе), но система нейтральная: меняются логотип, цвета, фото и тексты.

Принцип: сначала реальная структура, потом красота. Красота берётся из крупных фото, сетки, одного шрифта и воздуха, а не из придуманных элементов.

## Что внутри

| Файл | Что это |
|---|---|
| `templates/cart-template.src.html` | Корзина (состояние `main`) и окно «Edit Starter Kit» (`#modal`) |
| `templates/pdp-template.src.html` | Страница товара (`main`) и мини-корзина справа (`#cart`) |
| `templates/checkout-template.src.html` | Чекаут, шаг Information |
| `templates/render-ecommerce.py` | Рендер всех экранов в PNG 2560x1664 |
| `templates/checks/screen-check.js` | Проверка: текст не вылезает, фото не битые, кнопки не обрезаны |
| `tokens.css` | Цвета, радиусы, типографика |
| `logo/` | Логотип Ember: `ember-word.png`, `ember-mark.png`, `ember-original.png` |
| `sample-assets/` | Примеры фото пакетов и аксессуаров на прозрачном фоне |
| `preview/` | Готовые превью |

## Запуск

```bash
cd shared/fonts && npm install && cd ../..
pip install playwright && playwright install chromium
python3 ecommerce/templates/render-ecommerce.py --assets <папка с фото + av.jpg> --out-dir out
# один экран: --only cart | pdp | checkout
```

В папке `--assets` лежат фото товаров (прозрачный PNG) и `av.jpg` (её фото для аватара, в репозиторий не кладётся).

## Система

- Страница белая. Единственные тонированные поверхности: плитки под фото (`--tile`) и маленькие бейджи (`--accent-soft`).
- Цвет бренда (`--brand`) только в баннере, бейдже корзины и главной кнопке. Всё остальное: тёмные чернила на белом и тонкие разделители.
- Один шрифт: Schibsted Grotesk. Без засечек-заголовков, без моно-подписей капсом.
- Окно макета: браузер macOS 1160x760 на мягком градиентном фоне, вьюпорт 1280x832, экспорт x2.
- Радиусы: поля 10, плитки 12, панели 16, модалки 18, кнопки-пилюли 999 только для маленьких действий.

## Скелеты экранов

**Корзина.** Баннер про бесплатную доставку, шапка (поиск слева, логотип по центру, меню, корзина с числом, аватар), хлебные крошки, заголовок «Cart» с числом товаров, таблица Product / Quantity / Total. Строка: фото 116 px, название, вариант, ссылки Save for later и Remove, степпер количества, итог справа. Справа панель Order summary: промокод, подытог, скидки, доставка, итого, Checkout, Secure checkout, блок с датой доставки. Налог не выдумываем: «Taxes calculated at checkout».

**Окно редактирования набора.** Центрированная модалка: заголовок, одна строка пояснения, поля-селекты с мини-фото, футер всегда виден (цена набора слева, Cancel и Save changes справа). Открытый выпадающий список показываем только если окно целиком остаётся видимым, иначе закрытым.

**Страница товара.** Галерея слева (крупное фото, 4 миниатюры), справа: источник, название, рейтинг, цена и цена за 100 г, описание, размер и помол, выбор покупки (разово или подписка со скидкой), количество и Add to cart, строка преимуществ.

**Мини-корзина.** Панель 440 px справа поверх страницы, затемнение, полоса бесплатной доставки, товары с мини-степперами, один допродажный товар, подытог, View cart, Checkout.

**Чекаут.** Минимальная шапка, шаги Cart > Information > Shipping > Payment, форма (контакт, адрес, способ доставки с датами), справа сводка с миниатюрами и бейджами количества, код скидки, итоги.

## Чего не делать (ломает реалистичность)

- Огромный serif-заголовок и мелкие моно-подписи капсом на каждой строке.
- «Чек» с рваным краем, шкалы обжарки и сегменты помола прямо в строках корзины, дровер-конструкторы и аккордеоны.
- Тонированный фон страницы и несколько тонированных карточек подряд.
- Эффекты: свечение, тяжёлое размытие, градиентные кнопки.

## Проверка перед отдачей

1. Фото соответствует названию товара (смотреть каждый кроп).
2. Вес и объём берутся с упаковки на фото (12 oz это 340 g).
3. Суммы сходятся: подытог, скидки, доставка, итого. Порог бесплатной доставки согласован с подытогом.
4. Даты и дни недели согласованы с текущей датой.
5. Последняя строка корзины не обрезана, окно и выпадающие списки не закрывают главные кнопки.
6. Нет повторяющихся списков и воды. Если что-то выглядит странно, предложить правку.

## Фото: шот-лист для нового бренда

Для каждого товара нужен продуктовый снимок на однотонном или прозрачном фоне, лёгкая тень, одинаковый ракурс и масштаб у всей линейки. Минимум для кита: 3 основных товара, 1 набор (составляется из тех же фото), 1 аксессуар, 1 допродажный товар. Для страницы товара ещё 2 детальных кадра (этикетка и обратная сторона). Чужую упаковку перекрашиваем под палитру бренда и ставим логотип клиента.

## Как сделать новый магазин

1. Скопировать `ecommerce/` в `<ниша>-shop/` или править копию шаблонов.
2. Заменить `logo/` (префикс `ember` на имя бренда, флаг `--brand` в `render-ecommerce.py`).
3. Поменять `tokens.css` и блок `:root` в шаблонах: `--brand`, `--brand-ink`, `--accent-soft`, `--tile`.
4. Заменить фото в `--assets` и тексты, пересчитать суммы и даты.
5. Прогнать рендер и проверку, посмотреть каждый экран.
