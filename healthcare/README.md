# Healthcare kit — Elyra

Утверждённая система для healthcare-продуктов: клиники, imaging, prior authorization, payer/medical ops. Любой новый healthcare-проект **продолжается от этого кита**: меняется только содержание экрана, навигация и немного оттенок. Весь путь заново (вайрфреймы, поиск референсов, арт-дирекшн, компонент-борд) **не проходится**.

## Что можно менять без согласования

- тексты, заголовок экрана, подзаголовок;
- пункты навигации и их иконки;
- количество и названия summary-карточек;
- колонки и строки таблицы, блоки боковой панели;
- текст и иконку hero-плашки (gold callout);
- лёгкий сдвиг оттенка зелёно-золотой системы (светлота и насыщенность те же, тон серьёзный).

## Что требует согласования

Другой каркас раскладки, другая пара шрифтов, сильно другая палитра — спросить один раз; тогда только этот проект выходит из режима кита.

## Шрифты

Space Grotesk 500 (−0.025em) — заголовки и цифры; Plus Jakarta Sans — UI; Geist Mono — ID и время; табличные цифры. Установка и запреты — [`../shared/fonts.md`](../shared/fonts.md). Instrument Serif запрещён.

## Логотип (`logo/`)

| Файл | Что это |
|---|---|
| `elyra-mark.svg`, `elyra-word.svg` | вектор знака (viewBox 0 0 777 750) и надписи (0 0 1185 516), fill-rule evenodd |
| `elyra-mark.png`, `elyra-word.png` | PNG-маски, подставляются в шаблоны вместо `__MARK__` / `__WORD__` и перекрашиваются через CSS mask |
| `elyra-original.png` | оригинал логотипа |

На светлом — forest-градиент `#2F7566 → #123A31`, на тёмном — cream. Под логотипом всегда вторая строка с названием организации. Если в брифе свой продукт/логотип — используется он в той же подаче.

## Шаблоны (`templates/`)

| Шаблон | Холст | Рендер | Выход |
|---|---|---|---|
| `screen-glass-template.src.html` | 1600×1000 × 1.6 | `render-screen.py` | `screen-main.png`, `screen-fail.png` (критическое состояние через `#fail`), 2560×1600 |
| `feature-bento-template.src.html` | 1440×936 × 1.778 | `render-feature-bento.py` | 2560×1664 |
| `brand-bento-template.src.html` | 1440×936 × 1.778 | `render-brand-bento.py` | 2560×1664 |

Обёртки `render-*.py` вызывают общий рендер [`../shared/render/render.py`](../shared/render/render.py); проверки переполнения текста лежат в `templates/checks/`.

Фото и аватары (`maya.jpg`, `elena.jpg`, `daniel.jpg`, `patel.jpg`, `p1–p6.png`) и скрин для мокап-тайла (`screen.png`) в репозиторий не входят — они свои у каждого проекта и передаются через `--assets <папка>`:

```bash
python3 healthcare/templates/render-screen.py --assets ~/project/assets --out-dir ~/project/out
```

Для правок копируйте шаблон в проект и передавайте его через `--template <копия>`; оригинал в ките не меняется.
